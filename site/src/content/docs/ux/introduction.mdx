Nobody Builds UX will be our interaction system: the patterns, reusable layouts and quality bar that every
Nobody Builds screen follows, written down in the [UX spec](/specs/ux-patterns/).

<div class="nb-todo not-content"><strong>Not yet.</strong> There's no Nobody Builds product yet, so there are no screens to design for. This section keeps the same shape as the Space Works kit so it's ready when there is.</div>

## The rules to remember

Until the spec exists, these carry over from the brand:

- **One bold moment per screen.** The builder, a Blueprint panel or an Unbounded phrase. Not all three.
- **Every status pairs colour with a word or an icon.**
- **Empty states name the next step.** "Nothing built yet. Lay the first brick."
- **Light and dark both pass contrast.** Use the [tokens](/tokens/reference/), never raw colours.

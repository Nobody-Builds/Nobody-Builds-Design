## Asleep on the job

A builder, out cold on a half-built wall. It's the joke in the name: nobody builds. The bricks say the
opposite: the work is real, and it's already started. The colours come straight from the drawing: the blue of
the zzz does the work, and the Hard Hat yellow brings the energy.

## One source of truth

Everything on this site is published straight from the
[Nobody-Builds-Design](https://github.com/Nobody-Builds/Nobody-Builds-Design) repository. Add it to any
Nobody Builds project as a git submodule and every surface draws from the same kit:

```bash
git submodule add https://github.com/Nobody-Builds/Nobody-Builds-Design.git design
```

Every semantic colour token, light and dark side by side. This page is generated from
[`tokens/tokens.json`](https://github.com/Nobody-Builds/Nobody-Builds-Design/blob/main/tokens/tokens.json), so it
is always current. In CSS, each token is a `--color-*` variable holding an sRGB triplet. The token names are
the same as the Space Works kit's, so a project can switch kits without code changes.

How the tokens behave:

- **`accent`** is Blueprint, the action colour. **`brand`** defaults to the accent, and is the one family a
  project may override with its own colour.
- **`emphasis`** is Hard Hat. It belongs to Nobody Builds and can never be overridden.
- **`success`** and **`danger`** are status colours outside the seven: a soft green and a red, because the
  builder has neither. **`warn`** is Brick; **`info`** is Sky.
- **`*-soft`** tokens are opaque tinted fills for pills and cards. **`*-ink`** tokens are the text colour that
  passes contrast on every surface.

Every value, with its contrast ratio, is checked by `scripts/build-tokens.py` and listed in the
[UI brand spec](/specs/ui-brand-spec/).
